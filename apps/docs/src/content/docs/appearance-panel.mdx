The Appearance button sits in the nav beside its collapse button. While the nav is closed, and on phones, it moves to the header. The panel opens as a sheet on the right, and from the bottom on phones. Escape or a click outside closes it.

| Section     | What it does                                                                              |
| ----------- | ----------------------------------------------------------------------------------------- |
| Theme       | Payload's own light and dark setting. Hidden when `admin.theme` is `'light'` or `'dark'`. |
| Palette     | The colors. Hidden when only one palette is allowed.                                      |
| Custom      | Turns the current palette into the editor's own colors. See [Palettes](../palettes/).     |
| Style       | The layout: Payload, Enhanced or Studio. Hidden when only one style is allowed.           |
| Fine-tune   | The options of the picked style, with Reset and Undo. See [Styles](../styles/).           |
| Share setup | Copies the setup as JSON, or pastes one another editor copied.                            |

## Where the setup is saved

A signed-in editor's setup is saved in Payload's own preferences, so it follows them to every browser. The server renders it, so pages never flash. The login page and other signed-out views show the site default.

## Share setup

Share setup copies the style, its options and the palette as JSON. When the palette is the editor's own, its colors come along, and pasting replaces the other editor's. The same JSON is valid plugin config, so it can become [everyone's default](../configuration/#make-a-shared-setup-the-default).
